# J&R Engenharia — portfólio de obras

Site para a J&R Engenharia em que a rolagem acompanha a obra: da preparação do terreno à residência concluída, com serviços e pedido de avaliação.

![Captura real de J&R Engenharia — portfólio de obras](captura.jpg)

## Funcionalidades

- Sequência visual da obra guiada pela rolagem
- Formulário de avaliação por tipo de serviço com continuação no WhatsApp
- Seções de obras, serviços e apresentação do engenheiro

## Tecnologias

HTML · CSS · JavaScript · Vercel
